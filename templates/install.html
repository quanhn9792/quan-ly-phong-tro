{{ icon("phone") }} Các bước cài

  1. iPhone: mở địa chỉ bằng Safari → đăng nhập → nút Chia sẻ ⬆︎ → Thêm vào MH chính.
  2. Android: mở bằng Chrome → đăng nhập → menu ⋮ → Cài đặt ứng dụng (hoặc Thêm vào màn hình chính).
  3. Mở app từ biểu tượng Cho thuê trên màn hình chính — chạy toàn màn hình như app thật.
  4. Gửi app cho khách: trang Khách thuê → Tạo link app → gửi qua Zalo.
